Trading Lab is mostly used with the mouse, so it has a short list of keyboard shortcuts. This page lists every one of them, plus the mouse actions that are worth knowing.

## Anywhere in the app

| Key | What it does |
|---|---|
| **F1** | Opens this Help library. It works from any screen, even while you are typing in a box |
| **Esc** | Closes whatever is open on top: a menu, a dropdown, a dialog box or the About window |
| **Alt+F4** | Closes the window, the usual desktop shortcut. **File → Exit** does the same |

## The chart

| Key | What it does |
|---|---|
| **Esc** | Cancels a drawing you have started, deselects a selected drawing, and returns to the **Cursor** tool |
| **Delete** or **Backspace** | Deletes the selected drawing |

The two chart keys do nothing while you are typing in a text box, so they will not delete a drawing by accident while you write a note. See *Drawing tools*.

## Boxes and dialogs

| Where | Key | What it does |
|---|---|---|
| **Symbol search** | **↑** and **↓** | Move through the results |
| | **Enter** | Chart the highlighted result |
| | **Esc** | Close the results and leave the box |
| **Chat message box** | **Enter** | Send the message |
| | **Shift+Enter** | Start a new line |
| **Question dialogs** (new watchlist, rename, reset account, save as watchlist) | **Enter** | Confirm |
| | **Esc** | Cancel |
| **Watchlists**, add-a-symbol box | **Enter** | Add the symbol |
| **Star menu**, new watchlist box | **Enter** | Create the list |
| **Settings**, key boxes | **Enter** | Save the key |
| **Position calculator**, symbol box | **Enter** | Load that symbol |
| **Congress screen**, symbol and member boxes | **Enter** | Look up or search |
| **Journal**, comment box | **Enter** | Add the comment |

Number boxes, such as the order ticket's quantity and prices, follow the usual rules. You can type a number, or click the little arrows, or use **↑** and **↓** in the box.

## Menus

- **Esc** closes an open title-bar menu or dropdown.
- With one menu open (**File**, **Chart** or **About**), moving the mouse across the title bar switches to the next menu without another click.
- Clicking anywhere outside a menu closes it.

## Mouse and touchpad actions

| Action | Where | What it does |
|---|---|---|
| **Scroll the wheel** | On the chart | Zooms in and out |
| **Drag sideways** | On the chart | Scrolls back and forward through history |
| **Drag an axis** | On the chart | Stretches the price or time scale |
| **Hover** | On the chart | Shows the crosshair with the exact price and time |
| **Click and drag a line** | On a draft or working order line | Changes its price. See *Order lines on the chart* |
| **Click** a drawing, then drag | On the chart, with the Cursor tool | Selects and moves it, and its round end handles reshape it |
| **Double-click** an empty part of the title bar | Title bar | Maximizes or restores the window |
| **Double-click** a list's tab | Watchlists | Renames the list |
| **Click** a column heading | Tables in the screener, industries and Congress screens | Sorts by that column. Click again to reverse |
| **Click** a symbol | Almost any list | Opens its chart |
| **Click** an index in the ticker | Top bar | Charts that index. **Hover** over the ticker to pause it |
| **Drag** the divider | Between the main panel and Claude | Makes either side wider |

## What is not there yet

Trading Lab does not have shortcuts for switching between screens, opening the order ticket, or changing the chart's time frame. There are no global hotkeys. Use the ribbon, the chart header and the menus for those.

If you want a quicker way to do something, you can ask Claude. For example, *Switch to the 15-minute chart* or *Add an RSI* does it from the keyboard in one message. See *The chat panel*.

## Tips

- **F1 is the fastest way to find help.** Press it, type in the **Search help** box, and click a result.
- **Press Esc first** if something odd is on the chart. It cancels half-finished drawings and returns to the normal cursor.
- **Enter sends, Shift+Enter adds a line** in the chat box. If a message is sent too soon, get in the habit of writing multi-line requests with **Shift+Enter**.
