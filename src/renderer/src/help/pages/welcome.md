Trading Lab is a place to **learn to trade without risking money**. You get real market data, a simulated brokerage account, research screens, a journal and a strategy library, and a Claude assistant that can see what you see and teach from it.

> Trading Lab is educational software. Nothing in it is investment advice, and no real orders are ever sent.

## How this Help is organised

| Section | What is in it |
|---|---|
| **Getting started** | Setup, a tour of the window, how the paper account works |
| **Charts** | The chart screen, time frames, studies, colors, drawing tools |
| **Trading** | The order ticket, order types, account, active trades, how fills work |
| **Research screens** | Quote, analyst, fundamentals, options, news, market, congress, screener |
| **Planning and learning** | Watchlists, position calculator, journal, strategy library |
| **Claude assistant** | The chat panel, its tools, trade ideas, example prompts |
| **Settings** and **Reference** | Keys, time zone, data and backups, updates, shortcuts, glossary, troubleshooting |

## Using the library

- Pick a topic in the list on the left, or type in **Search help** to filter it.
- Pages for a screen have an **Open this screen** button at the top.
- Use the arrows at the bottom of a page to read on in order.
- Open Help any time from **About → Help Contents** or by pressing **F1**.
